# SpringSense Homework · 主题工坊

这是 [SpringSense Homework](https://github.com/Kevinnb66699/SpringSense-Homework-Releases) 应用里「主题工坊」的数据仓库。同学们在应用的「外观壁纸 → 主题工坊」里分享自己写的自定义 CSS 主题，大家都能一键套用。

- 每个 issue 是一个主题，标题是主题的名字，正文里是介绍和 CSS。
- 👍（issue 上的 reaction）就是点赞，主题按 👍 多少排序。
- **请在应用里发布、更新和删除**：issue 正文最后有一段隐藏的数据（`<!-- springsense-theme … -->`），里面记着 CSS 的大小。直接在网页上改正文，应用会对不上、不再显示这个主题。
- 主题里不能引用网上的地址（字体、图片、样式表），只能用 CSS 变量、选择器和 `data:` 图片；引用了的发布不了、也套用不了。一个主题的 CSS 最多 60 KB。
- 浏览和套用不需要 GitHub Token；发布、点 👍 要先在应用的「设置」里连接 Token（classic Token，带 `public_repo` 或 `repo` 权限；fine-grained Token 写不了这个仓库）。
- 不是主题的 issue 应用不会显示。管理员：@Kevinnb66699
